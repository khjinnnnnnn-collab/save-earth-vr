# 바다를 구하라 VR — 리뉴얼 v0.2

Meta Quest 3의 브라우저에서 실행하는 환경 보호 WebXR 체험. 기존 Three.js 프로젝트와 바다 중심의 세 교육 주제, 보트 도입부, 엔딩 및 반복 체험을 유지합니다. 이 버전은 실제 기기 검증 전 프로토타입입니다.

## 실행 방법

- GitHub Pages 등 HTTPS 정적 웹 호스팅에 압축을 푼 폴더의 내용 전체를 올립니다. `index.html`, `src/`, `assets/`, `vendor/`가 같은 위치에 있어야 합니다.
- Meta Quest 3: Quest 브라우저에서 HTTPS 주소를 열고 **VR로 시작하기**를 누릅니다. 컨트롤러 두 개 중 편한 손을 사용합니다. 앱 설치는 필요하지 않습니다.
- PC: 같은 주소에서 **화면으로 체험하기**를 누릅니다. 로컬 테스트는 폴더에서 `python -m http.server 8080` 실행 후 `http://localhost:8080` 접속. 파일을 더블 클릭하는 file:// 실행은 지원하지 않습니다.
- 첫 화면의 '처음 사용하는 학생을 위한 조작 안내 표시'를 끄면 추가 조작 안내 패널만 숨깁니다. 미션 자막은 유지합니다.
- PC 개발용 URL 파라미터: `?autostart`, `?maxdt=0.15`(느린 테스트 환경용).

## 미션과 조작

| 활동 | Quest 3 컨트롤러 | PC |
| --- | --- | --- |
| 마스크 착용 | 중지 그립(옆면) 또는 검지 트리거를 눌러 잡기 | 왼쪽 클릭 |
| 산호초 정화 | 페트병 2개, 캔 2개를 그립으로 잡고 올바른 통 쪽에서 놓기. 작게 이동 후 놓는 던지기 보조도 지원 | 왼쪽 버튼을 누른 채 올바른 통 쪽으로 이동 후 놓기 |
| 거북이 | 비닐을 잡고 몸쪽으로 살짝 당기기 | 왼쪽 누른 채 드래그 |
| 물고기 | 중지 그립을 유지한 채 안전 가위로 매듭 두 곳을 조준하고 각각 검지 트리거 누르기 | 가위를 왼쪽 버튼으로 잡고 매듭에 조준, 스페이스를 각각 누르기 |
| 물범 | 고리를 잡고 손목을 약 25도 돌리기 | 왼쪽 누른 채 드래그 |
| 북극곰 | 얼음 3개를 잡아 비어 있는 표시 원을 향해 놓기 | 왼쪽 누른 채 표시 원 조준 후 놓기 |

PC 시점 변경: 오른쪽 버튼 드래그 또는 방향키. 잘못된 위치에 놓으면 물체가 돌아옵니다. 위치와 조준에는 넉넉한 판정 범위를 사용합니다. 세게 던지거나 실제로 걸을 필요가 없습니다.

미션 중 약 12초 동안 진행되지 않으면 자막 힌트와 조작 안내가 다시 표시되고, 약 45초 동안 진행이 없으면 바다 친구가 도와 다음 미션으로 진행합니다. 안내는 기본 7초 표시되며 성공 시 숨겨집니다. 제한 시간으로 인한 실패는 없습니다. 목표는 총 10개(쓰레기 4, 동물 3, 얼음 3)입니다.

## 리뉴얼 사항

- 참조 이미지의 청록색·보라색·분홍색 팔레트와 풍성한 산호초를 목표로, 판형·둥근 구슬형·가지형·항아리형 산호의 코드 생성 3D 모델을 추가했습니다. 실시간 조명, 수중 안개, 모래의 움직이는 물결 빛을 조정했습니다. 기존 생물·보트 모델은 유지했습니다.
- 반복 배치되는 산호는 인스턴싱을 유지하고, 형태별로 모델의 세그먼트 수와 개수를 제한했습니다. 실제 Quest 프레임은 아직 확인하지 않았습니다.
- 구조 지점 이동은 기존 연속 자동 이동 대신 암전 후 위치 전환을 사용해 멀미 위험을 줄이는 방향으로 변경했습니다.
- 산호의 색 회복은 건강한 바다를 상상하는 게임적 연출입니다. 실제 산호 백화는 수온 상승 등 원인이 있고, 얼음길은 북극곰을 돕는 가상의 일시적 행동입니다.

## 테스트 및 남은 작업

- 전체 JavaScript 모듈 문법 검사 완료.
- Node.js와 실제 Three.js 모듈을 사용한 모의 입력 로직 테스트에서 보트, 잘못된 분류 거절, 4개 정화, 3마리 구조(가위 2회), 얼음 3개, 10/10 엔딩 및 정리 흐름 확인.
- 실제 WebGL 브라우저 렌더링, Quest 3 컨트롤러의 물리 입력·진동·양안 UI, 프레임 및 멀미는 미검증. 기기 테스트 전 배포용 완성본으로 간주하지 마세요.
- 게임의 대상 연령은 기기 제조사의 사용 연령 및 보호자 관리 요건을 준수해야 합니다. 해당 요건 미달 학생에게는 PC 체험 모드를 제공합니다. 체험 전 안전 공간을 확보하고 짧은 동작을 안내하세요.
