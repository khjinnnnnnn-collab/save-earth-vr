# 🐢 바다를 구하라 VR (save-earth-vr)

초등학생(1~6학년)을 위한 환경 보호 VR 체험입니다. **Meta Quest 브라우저**에서 주소만 열면 바로 실행되는 WebXR 게임이며, 플레이 시간은 약 4분입니다.
모든 미션은 반짝이는 것을 **잡기만 하면** 끝나고, 제한 시간이 없습니다. 오래 멈춰 있으면 바다 친구들이 도와줍니다.

| 장면 | 내용 |
|---|---|
| 출발 | 다이빙 보트 위에서 스쿠버 마스크를 잡으면 바닷속으로 풍덩 |
| 산호초 마을 | 반짝이는 쓰레기 6개를 잡아 망태기에 담으면 하얗던 산호가 알록달록 되살아남 |
| 바다 친구 구조 | 거북이(비닐), 물고기 떼(유령 그물), 물범(플라스틱 고리) 구하기 |
| 북극 바다 | 얼음 조각 3개를 잡아 아기 북극곰의 얼음집을 넓히면 엄마 곰과 다시 만남 |
| 엔딩 | 깨끗해진 바다, 고래와 친구들의 축하, 바다 지킴이 인증 |

## 실행
- Quest: 브라우저에서 GitHub Pages 주소 접속 → **VR로 시작하기**
- PC: 같은 주소 → **화면으로 체험하기** (반짝이는 것을 클릭하면 잡기, 오른쪽 드래그/방향키 = 시점)
- 로컬: `python3 -m http.server 8080` → http://localhost:8080
- 개발용 파라미터: `?autostart`, `?maxdt=0.15`(느린 테스트 환경)

## 구조
- `src/engine.js` 렌더러·XR·트윈 / `src/input.js` 컨트롤러·마우스 / `src/grab.js` 잡기
- `src/toon.js` 만화풍 셰이딩(툰 + 테두리 빛 + 물결 무늬)
- `src/stages/ocean.js` 게임 진행 / `ocean_props.js`·`sea_props.js` 섬·동물·소품 / `src/lines.js` 자막 대본
